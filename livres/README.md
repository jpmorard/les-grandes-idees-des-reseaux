Pour découvrir les réseaux : initiation → guide mathématique → intelligence artificielle. Pour concevoir : ingénierie, puis intelligence artificielle selon la question. Pour reprendre une formation : récit → initiation → guide.

Les PDF comportent des sommaires et des liens entre volumes. Pour suivre ces renvois hors ligne, téléchargez les six PDF dans le même dossier.
